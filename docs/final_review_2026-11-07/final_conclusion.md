# 当前可保留的研究结论与定稿状态

五席模拟复审的综合意见为 **Major Revision（大修后再定稿）**。它是对研究材料的评估，不是具体场馆决定；没有可靠录用概率，也不代表五位独立人类专家。最新 F11/F12 的主要数字可复算，问题集中在中心论证、规则版本和证据边界尚未统一。

## 建议保留的保守结论

> 在已测数值工具返回任务与核验协议下，直接增加查询相关样本尚未建立跨模型稳定的核验收益。对选定查询，已有 bootstrap 程序能从相同展示样本提取判别信号；独立行抽样后仍观察到信号，但效果随任务及抽样变化，轻微扰动切片仍有大量漏检。因此，应分别评价证据的可用性与核验程序的证据利用。现有结果不能把失败全部归因于信息不足，也未建立通用检测上界、识别模型内部机制或证明新算法优势。

人话：模型收到了数据，仍可能接受错误返回；同样的样本中存在统计程序能提取的识错信号。我们应研究怎样可靠地核验，而不能把“多给几行”当成已经验证的解决办法。

## 数字支持与范围

- 原固定相关二十行：0d 标出错误 10/12、误标正确 1/12；模型对照只在这份原始证据上成立，并受格式、表示和计算条件限制。
- 独立抽样：161/240 错误被标出，14/240 正确值被误标，表内混合 AUROC=0.8184375。仍只有十二查询、六表，不是 240 个新任务；没有新模型回答。
- 轻微扰动切片检出 50/120，较大扰动切片 111/120；严重度与查询绑定，差异不是幅度因果效应。
- 两个 context 主对照区间都跨零，不能写成更多 context 无效、两模型等效或主效应反转。
