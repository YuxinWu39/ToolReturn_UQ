# 当前可写进论文的结论（作者修订，2026-11-07）

这次修订完成了已有结果的离线复算和结论收窄，**没有新增模型调用，也不要求重跑 Gemini / Qwen 或重训 scorer**。五席审稿原件保持不变；本文件不是新的录用决定或正式复审通过证明。材料已有可写的实证核心，但目前没有完整投稿稿件，尚不能称为定稿完成。

## 主要结论

> 在选定的数值工具返回任务中，单纯增加查询相关的可见行，尚未建立跨模型稳定的核验收益。同样展示的样本中，已有 bootstrap 核验程序能提取识错信号；独立重抽样后仍有信号，但效果随查询和抽样变化，轻微扰动仍存在较多漏检。因此，评估工具返回可信度，需要分别测量可见证据、核验程序与实际行为，不能把失败统一解释成信息不足。

人话：**模型看到了相关数据，也可能照收错误结果；这些数据里有时已经有足够让某个统计程序识错的线索。接下来值得研究的是怎样稳定利用这些线索。** “足够”仅指已测程序和条件，不是对所有任务或检测器的保证。

## 已有证据能支持到哪里

- 原固定 matched20：0d 检出 10/12 个错误、误报 1/12 个正确返回，表内 AUROC 0.917，描述性区间 [0.833, 1.000]。它读取同一份可见 CSV，但额外使用结构化查询及 2,000 次 bootstrap 计算；不能声称与提示式模型有相同表示、计算量或成本。
- 独立行抽样：同样 12 个查询，每个 20 次抽样，检出 161/240（67.1%），误报 14/240（5.8%）；表内混合 AUROC 0.818，[0.718, 0.915]。这是 240 个查询/抽样单位，仍只有 6 个表，不是 240 个独立新任务，没有对应的新模型回复。原单抽样和混合抽样估计对象不同，不能把两者差值解释成原结果偏差。
- 轻微扰动检出 50/120，较大扰动 111/120；扰动严重度与查询绑定，不能说已识别扰动幅度的因果效应。
- Gemini 的 matched20−random20 主对照为 +0.083 [−0.167, 0.333]；Qwen 为 0 [−0.333, 0.333]。未建立稳定收益，不等于更多 context 无效、两模型等效或效应反转。Qwen 仅评分层可核验，其 72 条原始回复缺档，保留为辅助结果。

## 已撤回或限定的旧表述

0o/0o* 只是用全表有限 Monte Carlo 估计 bias/spread 的特权参考分数。没有证明其排序最优；不再称作通用信息上界、可达极限，也不把分数差值称作可恢复/不可恢复的信息分解。旧日志保留，但其强解释由本修订及 F13 覆盖。

H1 的 subtle 与 plausible+subtle 协议不同，不能混用。两套切片均已补算；例如 4B T1r2 的置信度 P+S 配对诊断 AUROC 0.555 [0.505, 0.606]，上界没有低于 0.60。加上缺少 live sanity，不再笼统宣布 H1 已确认。完整 AP、分母、表数见离线审计；AP<2×base 在平衡配对中等于 AP<1，约束很弱。Gemini H5 仍未确认：轻微扰动仅 7/73 配对可评分，区间上界 0.667。

六组 learned scorer 的 clean 区间覆盖仅约 0.147–0.185，远低于注册门槛 [0.80,0.98]，高/低极端值 sanity 也均未过关。结论是此训练配置未形成合格 detector，不能推断 learned UQ 普遍无效。已经修复常数分数表被错误丢弃的代码；当前六个整体 surprise 配对切片中均没有常数表，因此这处修复本身不改变这些整体数字。P5 共同支持集已核对，但 gate 失败，真实污染上的相对增益检验保持 withheld；没有声称完成了有效 detector 的相对比较。

历史“0 challenges”仅是自动行为标记器的零标记，不能代替人工标注、证明模型从未怀疑。Gemini 的 50 条恢复轨迹中，首次后续 Python 调用成功 23 条、报错 27 条；37 条存在某次后续错误，其中 10 条在错误前已有成功调用。不能把这 37 条全部解释成错误触发了核验，也不能把成功执行解释成人为识错意图。

## 动作、权限与成本边界

| 部分 | 实际执行 / 权限 | 能否声称部署收益 |
|---|---|---|
| 固定返回 pilot | 判断已给定候选；没有实际工具重试或弃答控制器 | 不能 |
| 离线 0d | 只读取已展示样本和结构化查询；2,000 次 bootstrap；flag 阈值既定 | 仅检测指标，未测端到端延迟和净错误成本 |
| P4 恢复 | 允许后续调用；poison_once 后重查可得到干净结果 | 只能报告已观测轨迹，不能推广到持续污染 |
| 保存的模型 usage | 请求记录中的用量信息 | 不等于与离线统计程序预算相同，未建立成本优势 |

flag 表示候选动作的触发信号，不表示已修正答案；未 flag 也不保证正确。若要主张系统收益，需另定策略（重查/弃答/接受）、持续污染条件和延迟、额外调用、误报代价协议。
